# Подбор автозапчастей

Поиск запчастей и аналогов через API Favorit Parts ([документация](https://lk.favorit-parts.ru/static/wsprice.pdf)).

Стек: React, Redux Toolkit (RTK Query), Bootstrap, Vite.

## Запуск

Нужно создать локально файл `.env` с двумя параметрами: адрес API `VITE_FAVORIT_API_URL` и ключ покупателя `VITE_FAVORIT_KEY`. В `.env.example` лежит демо-ключ из документации, с ним всё работает. 

```bash
npm install
cp .env.example .env
npm run dev
```

```bash
npm run build
npm run preview
```

Остальные команды:

```bash
npm run lint      # ESLint
npm run format    # Prettier
npm run build     # сборка
```

## Как пользоваться

1. Вводим артикул, после паузы в наборе приходит список производителей. Те, у кого есть наличие, идут первыми.
2. Кликаем по производителю, справа появляются сама деталь и её аналоги с ценами, остатками и датами отгрузки по складам.

По умолчанию показываются только позиции в наличии, переключатель над списком это меняет. Длинные списки выводятся по 20 позиций.

Поиск сохраняется в адресе (`?q=01089&brand=ASAM&number=01089`), так что ссылкой можно поделиться, а кнопка «Назад» возвращает к предыдущему выбору.

## Структура

- `api/` — RTK Query: запросы, разбор ответов и ошибок
- `store/` — слайс поиска и селекторы
- `hooks/` — вся логика компонентов
- `components/` — разбиты по папкам: `common`, `layout`, `search`, `brands`, `offers`
- `constants/` — тексты интерфейса и настройки
- `utils/` — форматирование, сортировки, склонения, работа с URL

Импорты из `src` идут через алиас `@/`.

## Заметки

- Цена берётся со складов (`warehouses[].price`), поле `price` у товара документация просит не использовать.
- Если деталь не найдена, API возвращает «пустую» позицию с нулевым `goodsID` — она отфильтровывается.
- Ответы кэшируются: повторный выбор того же производителя не идёт в сеть.
- У запросов таймаут 15 секунд. Если в `.env` чего-то не хватает, запрос не отправляется, а показывается понятная ошибка.
